# Доступ к порталу по группам — стенд (15.11.2026)

Задача: tasks/access_launch.md. Решения Т. В. от 02.11. Ответ системных администраторов от 13.11: группы и права — «Да»; регистрации, перевод между группами и блокировку ведут Сотрудник80 И. В. и Сотрудник1 А. В.

## Что сделано

| Часть | Файл | Суть |
|---|---|---|
| Карта «раздел → группы» | `portal/build/access_map.json` | Страницы групп; `implies`: суперадминистратор → все группы, администраторы → автотранспорт, производство, продажи. Что не перечислено — общие разделы. Флаг `on`: пока действует общий пароль, он `false` |
| Ключи наборов | `portal/app_build/access.py` | Набор = отсортированные группы страницы («sales», «prod+sales»). Ключ набора = HMAC-SHA256(gsec, `set:<набор>:<эпоха>`). gsec хранится только в enc_secret.json. Блокировка уволенного: растёт эпоха наборов его групп |
| Сборка | `portal/app_build/build_enc.py` | Блок страницы группы шифруется ключом набора. В m.bin у файла четвёртое поле — набор. При выключенном флаге всё как раньше |
| Личные ключи | `portal/app_build/acct.py` → `write_keyring(..., pay)` | `k/<id>.bin` = AES-GCM(K человека, 32 байта ключа сайта + JSON {набор: ключ}). Старый формат (только 32 байта) читается по-прежнему |
| Вход | `portal/build/acct/acct_core.js` → `takeKr` | После входа ключи наборов ложатся в IndexedDB «sets» как неизвлекаемые CryptoKey |
| Service Worker | `portal/app_build/enc/enc_sw.js` | Файл с набором расшифровывается ключом набора. Нет ключа — страница «Этот раздел открыт только своей группе» (403), на устройство блок не сохраняется. Ключи наборов обновляются с каждой версией, на «lock» стираются |
| Стенд | `ci/access_stand.py` + `ci/test_access_groups.js` | Малая копия портала, ТЕСТОВЫЙ пароль, пять тестовых людей (продажи, производство, автотранспорт, администратор, без группы) |

## Результат стенда (15.11.2026, ~10:20 МСК)

```
sales  наборы: prod+sales, sales | открыто: home calls sales stock | закрыто: staff transport plan
prod   наборы: prod, prod+sales  | открыто: home calls staff stock | закрыто: sales transport plan
auto   наборы: auto              | открыто: home calls transport   | закрыто: sales staff stock plan
admin  наборы: все               | открыто: всё                    | закрыто: —
none   наборы: —                 | открыто: home calls             | закрыто: sales staff stock transport plan
ALL OK
```

Ключом сайта не открывается ни один блок страниц групп: проверено напрямую на sales, staff и transport. Полная проверка перед выкладкой (флаг выключен) проходит: drive_pack.

## Что дальше

1. Группы людей задаёт «Управление»: поле `g` у пользователя в keyring (скрипт учётных записей). До этого группы берутся из `app_build/access_people.json` (id → группы).
2. Регистрация по рабочей почте: код с 1c@, заявку одобряет администратор.
3. Блокировка: `access.block()` увеличивает эпоху наборов; выкладка перевыдаёт ключи остальным.
4. Камеры (только суперадминистратор) и ГЛОНАСС (суперадминистратор и автотранспорт) — это данные хостинга, а не страницы. Группы `cams` и `glonass` уже заведены. Нужен отдельный ключ для st/*.bin.
5. «Документы: общие + свои» — набор на документ в реестре.
6. Флаг `on` включается только после того, как администраторы заведут людей. Дату отключения общего пароля Т. В. назначает сам.

Ревью: Рекс. Выкладка с включённым флагом — только после ревью и слова Т. В.
