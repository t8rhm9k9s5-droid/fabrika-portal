# Фабрика — портал предприятия (код)

Код внутреннего портала «Фабрика»: сборка сайта (portal/), робот хостинга (robot/), боты MAX и Telegram на Google Apps Script (bots/),
генератор оргструктуры (struktura/).

Выложено для проверки кода (CodeQL, ревью). Ключи, токены, адреса скриптов, почты, телефоны, идентификаторы чатов и ФИО сотрудников
заменены заглушками (`REDACTED_*`, `userN@example.org`, «СотрудникN», «ИмяN»; одно и то же значение — одна заглушка), поэтому код в таком виде не запускается — это копия для чтения.
Данные портала (отчёты, справочники, фото) в репозиторий не входят.
